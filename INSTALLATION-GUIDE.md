# Hospital Tourism India - Complete Website Package

## Installation & Setup Guide

### Quick Start
1. Create a folder named `hospital-tourism`
2. Inside, create two subfolders: `pages` and `assets`
3. Download each file below and save in the appropriate folder
4. Open `index.html` in your browser

### File Structure
```
hospital-tourism/
├── index.html
├── pages/
│   ├── treatments.html
│   ├── hospitals.html
│   ├── facilities.html
│   └── contact.html
├── assets/
│   ├── style.css
│   └── script.js
└── README.md (this file)
```

### Files to Download
See the separate files provided for:
- index.html
- treatments.html
- hospitals.html
- facilities.html
- contact.html
- style.css
- script.js

### How to Use

**On Your Computer:**
1. Create folder structure as shown above
2. Save each HTML file in the appropriate location
3. Save CSS and JS in the assets folder
4. Open index.html with any web browser

**On a Server:**
1. Upload all files maintaining the folder structure
2. Access via: http://your-domain.com/index.html

**With Python (Local Testing):**
```bash
cd hospital-tourism
python -m http.server 8000
# Open http://localhost:8000 in browser
```
